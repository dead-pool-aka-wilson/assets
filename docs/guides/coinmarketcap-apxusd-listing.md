## 10. Common Pitfalls to Avoid

1. **Superlatives:** CMC will reject descriptions containing marketing-heavy or hyperbolic language. Stick to factual, third-person descriptions.
2. **Incomplete Links:** Ensure all social media links are correct and active. Broken links can delay the listing process.
3. **Supply Discrepancies:** CMC verifies supply data against block explorers. Ensure the numbers provided match the on-chain data.
4. **Low Liquidity:** CMC may delay listing if liquidity is too low. Ensure the Curve pool has sufficient depth.
5. **Marketing Language:** Avoid phrases like "join our community" or "don't miss out". Focus on the technical and functional aspects of the project.
6. **Incorrect Contract Address:** Double-check the contract address on Etherscan before submitting.
7. **Missing Audit:** CMC highly values security audits. Ensure the audit link is prominent and valid.
8. **Unprofessional Email:** Use an official project email address rather than a personal one (e.g., Gmail, Outlook).

## 11. Verification & Post-Submission

## 14. Field-by-Field Detailed Instructions

### 14.1 Basic Information
- **Email Address:** Use an email address associated with the project's domain. CMC prioritizes requests from official domains.
- **Subject:** Follow the format `[Project Name] - [Ticker] - [Request Type]`.
- **Relationship with Project:** Be honest about your role. CMC may request verification of your identity or role.
- **Project Launch Date:** This is the date the token was first deployed on the mainnet.

### 14.2 Project Details
- **Project Name:** Use the full name as it should appear on CMC.
- **Symbol / Ticker:** Use the ticker as it appears on the block explorer.
- **One-liner:** Keep it concise and informative. Avoid marketing fluff.
- **Tags:** Select tags that accurately describe the project's category and features.
- **Project Description:** Use the pre-written description provided in the Appendix.

### 14.3 Technical Details
- **Platform:** Specify the blockchain the token is deployed on (e.g., Ethereum).
- **Contract Address:** Provide the correct contract address. Double-check for typos.
- **Decimals:** Ensure the decimals match the contract's configuration.
- **Block Explorer URL:** Provide a link to the token's page on a major block explorer like Etherscan.
- **Audit Link:** Provide a direct link to the audit report or the auditor's certificate page.

### 14.4 Links & Social Media
- **Website:** Provide the primary website for the project.
- **Whitepaper / Docs:** Provide a link to the project's documentation or whitepaper.
- **Social Media:** Provide links to all active social media channels. Ensure the profiles are up-to-date.
- **CoinGecko URL:** Providing the CoinGecko link can help CMC verify the project's existing market presence.

### 14.5 Supply Data
- **Circulating Supply:** This is the amount of tokens currently in the hands of the public.
- **Total Supply:** This is the total amount of tokens that have been minted.
- **Max Supply:** This is the maximum amount of tokens that can ever exist. For apxUSD, this is 0 (infinite).
- **Supply APIs:** Providing APIs for circulating and total supply can help CMC automate the data updates.

### 14.6 Exchange & Market Data
- **Exchange Name:** List the exchanges where the token is currently traded.
- **Pair:** Specify the trading pairs (e.g., apxUSD/USDC).
- **Pair URL:** Provide a direct link to the trading pair on the exchange.
- **Liquidity:** Provide the current liquidity in USD.
- **24h Volume:** Provide the trading volume over the last 24 hours.

### 14.7 Team & Traction
- **Headquarters Country:** Specify the country where the project is based.
- **Team Members:** List key team members and provide links to their LinkedIn profiles.
- **Backers / Investors:** List any notable investors or backing organizations.
- **Holder Count:** Provide the current number of unique token holders.

### 14.8 Additional Fields
- **Logo URL:** Provide a link to a high-quality logo. CMC has specific requirements for logo size and format.
- **CMC Dexscan URL:** If the token is already tracked on CMC Dexscan, provide the link.
- **Annex A:** Use this section to provide any additional information that doesn't fit into the other fields.

### 14.9 Final Review Before Submission
- **Accuracy:** Ensure all data is accurate and matches on-chain information.
- **Consistency:** Ensure the project name and ticker are consistent across all fields.
- **Formatting:** Check for any formatting errors in the description or other text fields.
- **Links:** Test every link one last time to ensure they all work as expected.
- **Attachments:** If CMC allows attachments, consider including the audit report or a project deck.

### 14.10 Post-Submission Monitoring
- **Ticket ID:** Keep a record of the ticket ID provided by CMC.
- **Email Communication:** Check your email regularly for any updates or requests from CMC.
- **Listing Status:** Periodically check CMC to see if the token has been listed.
- **Community Updates:** Keep your community informed about the progress of the listing.
- **Data Maintenance:** Once listed, ensure you have access to the CMC developer portal to maintain your project's data.
- **Market Expansion:** Continue to work on getting listed on more exchanges to increase visibility and liquidity.
- **Security Updates:** If you have any new audits or security updates, ensure they are reflected on CMC.
- **Partnership Announcements:** Announce any new partnerships or integrations that could enhance the project's credibility.
- **Supply Changes:** If there are any significant changes in supply, update CMC immediately.
- **Contact Information:** Ensure your contact information on CMC remains up-to-date.
